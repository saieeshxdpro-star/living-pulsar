# Living Pulsar

An interactive 3D space simulation and visualization project focusing on a pulsar star rendered in real-time in the browser.

## 🚀 Live Demo
Experience the live project here:  
👉 [Living Pulsar Live](https://saieeshxdpro-star.github.io/living-pulsar/)

---

## 🕹️ Controls

| Action | Control |
| :--- | :--- |
| **Orbit Viewport** | `Left Click` + `Drag` |
| **Optical Zoom** | `Mouse Wheel` |

---

## 🛠️ Built With
* **Three.js / WebGL** (for 3D rendering and astronomical visual effects)
* **HTML5 / CSS3 / JavaScript**
* Hosted on **GitHub Pages**
